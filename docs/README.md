# Documentation

Use the document that matches the task:

- [Configuration](configuration.md): Agent options, runtime tuning, supervisor,
  optional model review, and optimizer settings.
- [Deployment](deployment.md): local, Docker Compose, and hardened systemd
  installation, operations, rollback, and uninstall procedures.
- [Strategy](strategy.md): deterministic resource, survival, defense, scouting,
  and bounded-combat policy.
- [Release checklist](release-checklist.md): credential hygiene, validation, and
  GitHub release requirements.

The tested compatibility contract is maintained in the repository README and
checked by the unattended version monitor. Arena Hero's upstream gameplay
documentation remains available at <https://doc.arenahero.io/>.
